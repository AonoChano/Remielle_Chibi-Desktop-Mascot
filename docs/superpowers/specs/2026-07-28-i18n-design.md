### i18n 引擎 (i18n.js)

零依赖，~80 行代码：

**功能：**
1. `load(dict, localeCode)` — 加载翻译字典
2. `t(key)` — 按点分路径取翻译（如 `t('anim.drawing')`）
3. `scan()` — 扫描 `[data-i18n]` 元素并替换文本
4. `scanAttr(attr)` — 扫描 `[data-i18n-attr]` 元素替换属性（如 placeholder）
5. `setLocale(localeCode)` — 切换语言，重新加载字典 + 重新扫描
6. `getAvailableLocales()` — 返回已加载的语言列表（含 display_name）

**回退机制：**
- 缺失 key 时：当前语言 → en-US → zh-CN → 返回 key 本身
- 确保界面永远不会出现空白

**文件扫描与加载：**

Electron 主进程通过 `fs.readdirSync` 扫描 `locales/` 目录，读取所有 `.json` 文件，验证 `_meta` 结构后注册为可用语言。语言列表通过 IPC 发送给面板。

```javascript
// main.js
function scanLocales() {
  const localesDir = path.join(__dirname, 'locales');
  const files = fs.readdirSync(localesDir).filter(f => f.endsWith('.json'));
  const locales = {};
  for (const file of files) {
    try {
      const content = JSON.parse(fs.readFileSync(path.join(localesDir, file), 'utf8'));
      if (content._meta && content._meta.locale && content._meta.display_name) {
        locales[content._meta.locale] = content;
      }
    } catch (e) {
      console.warn(`Skipping invalid locale file: ${file}`);
    }
  }
  return locales;
}
```

**鲁棒性：**
- JSON 解析失败 → 跳过该文件，console.warn
- 缺失 `_meta` → 跳过
- 缺失 key → 回退链
- locales 目录不存在 → 使用硬编码兜底字典

### HTML 标记

```html
<div class="logo" data-i18n="app.title">小蕾米</div>
<h2 data-i18n="anim.title">动画播放</h2>
<button data-i18n="anim.idle" data-anim="a">待机 Idle</button>
```

- `data-i18n` 属性值 = JSON 中的点分 key
- 元素的初始文本作为 fallback（JS 未加载时也能显示）
- `data-anim` 等功能属性保持不变

### 语言切换 UI

设置 tab 新增"界面语言"行，下拉菜单选项从已加载的 locales 动态生成：

```html
<div class="setting-row">
  <label data-i18n="settings.language">界面语言</label>
  <select id="locale-select">
    <!-- 动态填充 -->
  </select>
</div>
```

```javascript
// panel.js
const locales = await window.electronAPI.invoke('get-locales');
const select = document.getElementById('locale-select');
for (const [code, dict] of Object.entries(locales)) {
  const opt = document.createElement('option');
  opt.value = code;
  opt.textContent = dict._meta.display_name;
  select.appendChild(opt);
}
```

### IPC 通道

| 通道 | 方向 | 用途 |
|------|------|------|
| `get-locales` | panel→main (invoke) | 获取可用语言列表 |
| `set-locale` | panel→main (send) | 切换语言，main 广播给所有窗口 |
| `locale-changed` | main→pet/panel | 通知语言已切换，携带新字典 |

### locales/README.md 贡献指南

```markdown
# 翻译贡献指南

感谢你为 Remielle 桌宠贡献翻译！

## 如何添加新语言

1. 复制 `en-US.json` 并以你的语言代码命名（如 `ja-JP.json`）
2. 修改 `_meta` 中的 `locale` 和 `display_name`
3. 翻译所有 value（保持 key 不变）
4. 提交 PR

## 规则

- 文件名使用 IETF 语言标签（如 `zh-CN`、`en-US`、`ja-JP`）
- `_meta.locale` 必须与文件名一致
- `_meta.display_name` 用该语言本身书写（如日本语表示"日本語"）
- 未翻译的 key 可以删除，系统会自动回退到英语 → 中文
- 不要修改 key 名称

## 回退顺序

当前语言 → en-US → zh-CN → key 本身
```
