# 扁平控制面板设计

## 目标

统一“桌宠”和“设置”页面的控制样式，去掉显眼的独立白色卡片。所有简单开关使用同一套透明横排和胶囊控件；设置页改为紧凑的扁平列表，并让“窗口置顶”成为真实、持久化的功能。

## 桌宠页

- “眼神鼠标追踪”和“进行动画控制测试”都使用 `.feature-row`。
- 文本左对齐，44×24px 胶囊开关右对齐。
- 两行共享左右边界、字号、行高、焦点状态和开关颜色。
- 行背景透明、无卡片圆角、无阴影。
- 两行之间使用一条低对比度分隔线。
- 测试模式的业务逻辑不变：开启后自动状态机、双击、抽卡和计时停用，只允许面板手动动画控制。

## 设置页

设置页保留标题，下方使用单一 `.settings-list` 容器。容器本身不填充卡片背景，每一项使用 `.settings-control-row`：

- 左侧 `.setting-copy` 包含设置名称和可选说明。
- 右侧 `.setting-control` 包含下拉框、胶囊开关或状态标签。
- 行的最小高度为 64px，行与行之间使用 `rgba(123, 107, 94, 0.12)` 的 1px 分隔线，最后一行无分隔线。
- 右侧下拉框宽度使用 `clamp(140px, 30vw, 220px)`。
- 在面板允许的最小 640px 视口宽度下仍保持左右布局，且 `scrollWidth <= clientWidth`。

### 角色尺寸

- 左侧名称“角色尺寸”。
- 右侧为固定最大宽度的紧凑下拉框。
- 名称使用带 `for="size-select"` 的原生 label。
- 现有尺寸选项与缩放行为不变。

### 界面语言

- 左侧名称“界面语言”。
- 右侧为与尺寸控件同宽的紧凑下拉框。
- 名称使用带 `for="locale-select"` 的原生 label。
- 现有动态语言扫描和切换行为不变。

### 窗口置顶

- 左侧显示名称与现有说明。
- 右侧使用与桌宠页相同的胶囊开关。
- 默认开启。
- 主进程中的布尔值是单一事实来源。
- settings JSON 键固定为 `alwaysOnTop`；缺失或非布尔值回退为 `true`。
- IPC 契约固定为：
  - `get-always-on-top`：返回当前已确认布尔值。
  - `set-always-on-top(enabled)`：仅接受 boolean，成功后返回最终值。
  - `always-on-top-changed`：主进程向面板广播已提交值。
- 设置改变时立即调用桌宠窗口的 `setAlwaysOnTop(enabled)`，保存到 settings JSON，并向面板广播最终值。
- 桌宠窗口重建时使用持久化值创建窗口。
- 即使桌宠窗口当前不存在，也必须持久化并广播设置；下次创建窗口时应用该值。
- 面板使用有返回值的 IPC；请求失败时恢复上一个值并记录警告。
- 非布尔载荷必须拒绝，且不得改变窗口或持久化设置。

### 开机自启

- 本次不实现系统自启动。
- 左侧显示名称与说明，整行使用弱化颜色。
- 右侧显示“暂未实现”状态标签，不显示一个看似可操作的开关。

## 可访问性

- 所有胶囊控件底层都使用原生 checkbox 与 `role="switch"`。
- 文本通过 `aria-labelledby` 关联开关。
- 键盘焦点环保持可见。
- 窗口置顶请求进行中时临时禁用开关，并通过样式表现不可操作状态。

## 错误处理

- 主进程未就绪或 IPC 失败时，面板回滚到最后确认值。桌宠窗口不存在不是失败，设置仍应提交。
- 重复设置相同值是幂等操作，不重复写设置或广播。
- 创建桌宠窗口时若设置缺失或类型非法，回退为 `true`。
- 设置提交使用以下事务顺序：
  1. 记录旧值；若桌宠窗口存在，先尝试应用新窗口状态。
  2. 严格写入 settings JSON；写入函数必须返回成功或抛出，不能吞掉错误后仍确认成功。
  3. 写入失败时尝试把存活窗口恢复为旧状态，并向面板拒绝本次请求。
  4. 两步都成功后才更新内存真值并广播。
  5. 若窗口应用本身失败，不写磁盘、不更新内存、不广播。

## 测试

- 面板合同测试确认两个桌宠开关都使用 `.feature-row` 和 `.toggle-switch`。
- 面板合同测试确认旧的桌宠页测试卡片结构已移除。
- 设置页合同测试确认扁平列表、紧凑下拉框、置顶开关和禁用状态标签。
- 设置页合同测试确认尺寸和语言下拉框具有原生可访问名称。
- 窗口置顶服务测试覆盖默认值、布尔校验、幂等设置、持久化、广播和窗口重建应用。
- 窗口置顶服务测试覆盖窗口应用失败、持久化失败后的窗口回滚，以及无桌宠窗口时仍持久化。
- 测试模式回归测试确认开关仍发送 `set-test-mode`、显示或隐藏手动控件、保存并恢复状态，且状态机的测试独占语义不变。
- 隐藏 Electron QA 分别以 860px 和最小 640px 宽度加载桌宠页与设置页，检查计算样式、控件对齐、透明背景，并断言 `scrollWidth <= clientWidth`。

## 不在本次范围

- 不改变尺寸、语言、动画测试和眼神追踪的既有业务逻辑。
- 不实现开机自启。
- 不重新设计侧栏、Logo、关于页或动画按钮。
