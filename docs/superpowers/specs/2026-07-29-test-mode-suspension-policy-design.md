# 测试模式暂停协议设计

## 目标与范围

动画控制测试开启时，所有会干扰测试的功能必须停止运行，并在面板中灰化且不可操作。暂停不得改写用户的持久化开关值；退出测试后按原配置恢复。

当前暂停自动动画状态机、抽卡、计时、桌宠双击交互和眼神鼠标追踪。尺寸、语言、窗口置顶及手动动画测试控件保持可用。

## 面板声明协议

- 需要停用的设置区域声明 `data-test-mode-policy="suspend"`。
- 面板统一查询该声明，不维护控件 ID 白名单。
- 开启时设置 `inert`、`aria-disabled="true"` 和 `.is-test-suspended`；退出时统一移除。
- `inert` 不覆写后代控件原有的 `disabled` 值，避免异步请求和测试模式互相覆盖。
- 灰化样式使用声明选择器；未来新增暂停项只需添加声明。

当前仅眼神追踪行声明暂停。测试模式开关及手动动画控件不得声明暂停。

## 运行时暂停闸门

桌宠运行时提供功能闸门。功能以唯一名称注册 `suspend` 和 `resume` 回调：

- 状态切换对所有注册功能执行一次对应回调，重复设置幂等。
- 测试模式期间注册的新功能立即暂停。
- 单个回调失败时记录诊断日志并继续处理其他功能。
- 注册返回注销函数；拒绝同名重复注册。

自动动画状态机和眼神追踪接入该闸门。闸门只协调生命周期，不保存用户设置。

## 眼神追踪

- 开启测试后停止采集鼠标目标，并沿用现有插值平滑回中。
- `eyeTrackingEnabled` 及磁盘设置保持原值。
- 退出测试后，仅在用户原本开启时恢复追踪。

## 自动动画

- 现有 `TEST_MODE` 状态继续清空轨道、停止抽卡与计时并拒绝双击。
- 统一闸门负责调用行为控制器；手动动画 IPC 仍仅在测试模式下接受。
- 退出测试模式后按既有约定回到 `IDLE`。

## 日志与测试

- 闸门记录状态变化、功能名、暂停或恢复结果及异常，沿用 `[pet-behavior]` 诊断通道。
- 单元测试覆盖暂停、恢复、幂等、开启期间注册、注销和故障隔离。
- 面板合同测试覆盖声明、`inert`、ARIA 和统一灰化样式。
- 桌宠合同测试覆盖眼神追踪同时受用户设置与测试暂停状态约束。
- Electron QA 验证眼神追踪灰化且不可操作，非暂停设置及手动测试控件保持可用，退出后恢复。

## 不在范围

- 不改变动画概率、循环次数或计时规则。
- 不停用窗口拖动、右键菜单、尺寸、语言或窗口置顶。
- 不迁移测试模式持久化方式。
