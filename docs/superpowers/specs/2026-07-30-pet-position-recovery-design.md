# 桌宠位置恢复设计

## 问题

尺寸变化后的延迟保存使用数组方式解构 BrowserWindow.getBounds()，但 Electron 返回的是 bounds 对象，因此触发 object is not iterable。桌宠也可能被拖到显示器工作区之外，用户需要从控制面板找回。

## 修复

- 尺寸保存改为从 bounds 对象读取 width。
- “桌宠”页新增“重置至屏幕中央”命令，使用有返回值的 reset-pet-position IPC。
- 目标显示器取当前控制面板所在显示器；控制面板不可用时回退主显示器。
- 使用显示器 workArea 计算中心，排除任务栏区域。
- 桌宠大于工作区时锚定工作区左上角，保证至少有稳定的可恢复位置。
- 新坐标立即写入设置，后续启动沿用。
- 位置恢复不干扰动画测试，因此测试模式开启时按钮保持可用。

## 验证

- 单元测试覆盖带负坐标或正偏移的多显示器工作区，以及桌宠大于工作区的情况。
- 合同测试覆盖按钮、多语言、IPC 白名单、主进程处理器和 bounds 对象读取。
- 隐藏 Electron QA 覆盖桌宠页在 640px 与 860px 宽度下无横向溢出，并确认按钮在测试模式中保持可操作。
